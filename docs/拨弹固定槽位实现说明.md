# 拨弹固定七点单发

2026-10-25，基于 main / 67e2b19。手动 FIRE、AUTOAIM、REAL 发射阶段共用固定七点单发。云台死区保留 1。

## 目标如何确定

不寻零，不根据摩擦轮电流找锚点，进入模式不自动送弹。收到第一次有效单发请求时，以当前拨弹位置作为数学参考位置，建立一组七等分目标；之后不使用每发的实际停车位置重设这组点。

沿用原代码拨弹传动比 36:1，拨弹盘一圈为 `8192*36=294912` 个编码器计数。`motor.h` 的 19:1 用于底盘轮速换算，不用于拨弹。

相对参考位置的七个点为：`0、42130、84261、126391、168521、210651、252782`。下一圈对应这些位置再加 294912。

第 k 个目标按 `参考位置+round(k*294912/7)` 直接计算，不反复累加截断后的 42130。第七次单发回到下一圈的同一相位。比如上一目标是 42130，实际停在 42030 或 42230，下一目标仍为 84261。

切换模式保留这组点。中途取消后，下次请求继续选择前方的固定点；若原目标已经到达或越过，则选择更前面的点。速度目标只允许正转或零速，过冲不会反转追回。

这只能减少逐发停车误差的累积，不能确定弹丸相对于机构的绝对相位；断电后这组参考位置也不保留。

## 发射入口

- FIRE：保留 ch[1] 的单发上升沿；ch[0] 连发分支已经注释，单独操作 ch[0] 不拨弹。
- AUTOAIM：只接受原有新鲜视觉单发指令的上升沿。
- REAL：只在摩擦轮开启的发射阶段接受视觉单发；按接受的单发动作计数，第 50 次停稳后才启动返程。
- 单发进行中收到的额外请求不排队，松开再触发才能请求下一发。
- 拨弹动作要求摩擦轮转速命令已开启；此处没有新增摩擦轮实际转速就绪判定。

## 运动参数

| 参数 | 当前值 |
|---|---|
| 单发起步 / 最大速度 | 150 / 1000 rpm |
| 加速 / 减速区间 | 3600 / 3000 计数 |
| 开始停车误差 | 剩余不超过 200 计数 |
| 停稳确认 | 绝对转速不超过 30 rpm，持续 100 ms |
| 运动 / 制动电流输出上限 | 4000 / 2000 原始命令单位 |

本轮新增的拨弹 CAN 反馈过期、堵转、运动/停稳超时、过冲、过温判定和故障锁存均已删除。不存在新增故障码或必须复位 MCU 才能继续发射的锁存分支。控制器只执行固定点单发、减速、停稳以及模式取消；摩擦轮继续按所选模式运行。CAN 接收标记只用于判断是否收到过完整电机反馈，不作 20 ms 超时判断。没有加入故意堵转找零、牺牲一发、事件偏移量或大容量 RAM 记录。

## 文件和验证

核心算法在 `RCS_code/STM32F405/feeder.h`；电机输出适配在 `motor.cpp` 的 `UpdateFeeder()`；手动连发注释位于 `RC.cpp` 的 FIRE 分支。

主机回归：`tests/run_feeder_tests.ps1`，以及用 Python 运行 `tests/feeder_control_test.py`。前者验证固定目标、停车误差、切模式、取消及取消故障锁存后的行为；后者提取真实 RC / SHOOTER / Motor 代码，验证连发关闭、单发边沿、摩擦轮命令联锁和 REAL 第 50 次完成。

主机回归与 VisualGDB 编译不等于实车停车精度验证；当前速度、停车容差和真实停止位置仍需在机构上核对。
